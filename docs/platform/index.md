# Platform

Things s&box gives every game, so you don't have to build them yourself.

## [Menu Scene](/platform/menu-scene.md)

Your game's own main menu, shown when players pick your game.

## [Text Chat](/platform/text-chat.md)

Text chat for multiplayer games, routed through the host and filtered for you.

## [Voice Chat](/platform/voice-chat.md)

Players can talk to each other with no setup. Add `Voice` components when you want more control.
